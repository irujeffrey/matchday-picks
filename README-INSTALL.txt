MATCHDAY — SELECTIVE DAILY RECOMMENDATIONS
==========================================

WHAT THIS REBUILD CHANGES
-------------------------
The site no longer publishes every fixture that clears a low threshold.

FOOTBALL RULES
--------------
- Uses API-Football's supplied 1X2 prediction percentages.
- Requires all three outcomes (Home, Draw, Away) to be present.
- Best outcome must be at least 75%.
- Best outcome must lead the second-best outcome by at least 12 percentage points.
- Only Home / Draw / Away selections are generated.

BASKETBALL RULES
----------------
- Uses API Ninjas basketball fixtures and standings.
- Both teams must have at least 10 games played.
- Their standings win-rate gap must be at least 20 percentage points.
- The existing heuristic estimate must be at least 70%.
- This is an experimental standings-based estimate, NOT a calibrated probability.
  It must not be interpreted as a guarantee or directly compared to football
  API percentages.

COMBINED SHORTLIST
------------------
- Football and basketball candidates compete for one combined shortlist.
- At most five selections are published per day.
- There is no quota for either sport.
- If no candidates qualify, the page displays no recommendations.
- The internal ranking score is a heuristic, not a cross-sport probability.

FILES
-----
site/index.html
    Responsive combined recommendations page with All / Football / Basketball filters.

scripts/build-picks.mjs
    Fetches the daily fixtures, applies strict selection rules, and writes
    site/picks.json.

.github/workflows/daily-picks.yml
    Runs the builder daily and deploys the site to GitHub Pages.

INSTALLATION
------------
1. Extract this ZIP into the root of your existing matchday-picks repository.
2. Keep the same folders and paths. Replace the existing files when asked:
   - site/index.html
   - scripts/build-picks.mjs
   - .github/workflows/daily-picks.yml
3. In GitHub, open your repository:
   Settings > Secrets and variables > Actions.
4. Add or confirm these repository secrets:
   - APIFOOTBALL_KEY
   - API_NINJAS_KEY
5. Open Actions and run "Build daily selective picks" manually once.
6. Confirm the workflow completes successfully, then open the GitHub Pages URL.

IMPORTANT
---------
- The daily data file site/picks.json is generated by the workflow. It is not
  committed to the source repository.
- The workflow requires GitHub Pages to be enabled and configured to use
  GitHub Actions as the deployment source.
- API plan quotas and endpoint availability can affect whether data is built.
- A strict filter may legitimately produce zero picks.
- No sports prediction is certain. "Strong" means it passed the stated filters,
  not that the outcome is guaranteed.
- The workflow uses the Europe/London calendar day to preserve the existing
  repository's date convention. If you want the daily slate based on Lagos or
  US calendar dates, that is a separate date-handling change.
